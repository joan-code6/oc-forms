# Unscored Applications

This page provides a comprehensive view of all applications that have been submitted but haven't been fully reviewed/scored yet.

## Features

### 📊 Spreadsheet View
- Displays all applications with status: pending, pending_2nd, in_review
- Shows key information in a tabular format for easy scanning

### 🔍 Advanced Filtering
- **Search**: Search by Minecraft IGN, Discord username, or App ID
- **Status Filter**: Filter by application status (pending, pending_2nd, in_review)
- **Timezone Filter**: Filter by timezone (perfect for finding NA people)
- **Sorting**: Sort by date, Minecraft IGN, or timezone

### 📈 Key Information Displayed
- **Application Details**: Minecraft IGN, Discord username, skin preview
- **Location/Timezone**: Helps identify NA applicants
- **Review Progress**: Shows reviewer count and status
- **Application Age**: When the application was submitted
- **Status Indicator**: Clear visual indicator of review progress

### 🎯 Perfect For
- Managers reviewing applications before midnight
- Finding and prioritizing NA applicants
- Tracking applications waiting for review
- Monitoring review queue progress

## Usage

Admins and moderators can access this page via:
- **URL**: `/moderator/unscored`
- **Navigation**: Available from the moderator dashboard (if admin access is enabled)

## How It Helps

This page solves:

1. **Finding NA people**: Timezone filter makes it easy to locate applicants in specific regions
2. **Tracking unscored applications**: Clear visibility into which applications still need review
3. **Review prioritization**: Sort by date or other criteria to prioritize reviews
4. **Spreadsheet perspective**: Organized view similar to a spreadsheet for easy analysis

## Status Legend

- **pending**: Submitted, waiting for first review
- **pending_2nd**: Reviewed once, waiting for second review
- **in_review**: Currently being reviewed by a moderator

Applications with status "reviewed" are already scored and won't appear here.
